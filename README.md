# AngularJS Registration and Login System

A simple registration and login web application developed using AngularJS.

## Features
- User registration
- User login
- Duplicate username validation
- Password validation (minimum 6 characters)
- Welcome message after successful login
- Logout functionality

## Technologies Used
- HTML
- CSS
- AngularJS 1.8.2
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `auth.html` in a web browser.
3. Ensure you have an internet connection because AngularJS is loaded using a CDN.
4. Register a user and test the login functionality.

## Project Structure
- `auth.html` – Contains the registration, login and welcome interface.
- `.gitignore` – Specifies files excluded from Git tracking.
- `README.md` – Project documentation.

## Note
This is a front-end demonstration project. User details are stored temporarily in browser memory and are not persisted after the page is refreshed. It is not intended for production authentication.
